# Minecraft para LightStream Desktop

Canal público de distribución para la integración de Minecraft en LightStream Desktop (Windows x64).

Los paquetes instalables y su manifiesto de versiones se publican en **Releases**. Este repositorio no contiene el código fuente de LightStream, credenciales, registros, cuentas de jugadores ni partidas personales.

LightStream Desktop verifica el tamaño y SHA-256 de cada descarga. Java y Prism Launcher se obtienen de sus canales oficiales, con versiones verificadas. Minecraft requiere una cuenta con licencia; el juego y sus recursos se descargan mediante Prism Launcher desde los proveedores oficiales.

Los mapas publicados son plantillas saneadas. Las partidas y cuentas se conservan localmente, separadas de los archivos de instalación y actualización. Descargar una versión nueva no reemplaza una partida existente.

El uso de Minecraft está sujeto al [EULA de Minecraft](https://www.minecraft.net/eula). Este proyecto no está afiliado a Mojang ni Microsoft. Los componentes de terceros conservan sus licencias y avisos.
